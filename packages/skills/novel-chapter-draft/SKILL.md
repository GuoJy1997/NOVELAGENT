# Chapter Draft

1. Load the chapter's beat list, relevant canon facts, and character states.
2. Draft prose beat by beat, keeping the established voice.
3. Check the draft against anti-slop rules before returning.
4. Return the chapter text plus a short summary of what changed for downstream consistency checks.
