# 导入完成提醒

> 状态：已确认  
> 日期：2026-08-20

## 问题

文件导入后模型会长时间流式输出。完成后自动写入对应页，但没有单独的“做完了”信号，用户不知道能否离开或查看结果。

## 决策

- 不使用弹窗。
- 人还在导入页上：流式区域收起，直接进入编辑器（大纲 / 世界观）或人物列表 / 关系图。页头状态为「已保存」。
- 同时用现有 `role="status"` 反馈条（`echo-action-feedback`）提示一句中文，约 3.2 秒后消失。
- 点这条提示会打开对应工作台页（大纲 / 世界观 / 人物）。人已在该页时，提示仍出现，只作确认。
- 失败同样走这条反馈，不弹窗。
- 不启用顶栏铃铛通知中心。

## 文案

| 事件 | 文案 | 跳转 |
| --- | --- | --- |
| 大纲写入成功 | 大纲已整理完成 | 大纲 |
| 世界观写入成功 | 世界观已整理完成 | 世界观 |
| 人物写入成功 | 人物已提取完成 | 人物 |
| 大纲失败 | 大纲整理失败，请重试 | 大纲 |
| 世界观失败 | 世界观整理失败，请重试 | 世界观 |
| 人物失败 | 人物提取失败，请重试 | 人物 |

关系页与人物共用 `characters.json`，完成/失败都按人物提醒。

## 非目标

- 不改 DeepSeek 超时 / 502。
- 不把反馈条改成第二套视觉壳。
- 不增加必须点「查看」才能进编辑器的中间页。
