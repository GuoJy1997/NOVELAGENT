# Novelora 驾驶舱空间重构第一阶段设计

日期：2026-07-22  
状态：用户已确认方案 A，等待书面复核

## 目标

以 `assets/参考图/image.png` 为视觉标尺，重构 Novelora 驾驶舱首屏的布局骨架、空间背景和核心关系图形。第一阶段结束后，1440×900 视口需要完整呈现小说结构、章节泳道和底部创作模块入口，并保留现有 mock 数据、交互行为和可访问性契约。

## 设计方向

采用方案 A：参考图对齐型高密度驾驶舱。

- 视觉语言：白绿液态、轻透、克制、精密。
- 版式特征：紧凑三栏、中央关系图主导、右侧 Agent 控制台高密度排列。
- 记忆锚点：绿色流体贯穿中央画布；书本与c Nova 组成左下场景，而不是独立贴图。
- 信息表达：Structure Map 和 Chapter Swimlane 使用节点、曲线和连续关系表达，不再依赖大尺寸卡片横排。

设计参数：`DESIGN_VARIANCE 7`、`MOTION_INTENSITY 5`、`VISUAL_DENSITY 8`。

## 页面骨架

桌面基准视口为 1440×900。

1. 左侧导航压缩宽度，保留品牌、导航、当前项目和场景资产。
2. 中央工作区占据主要宽度，顶部栏控制在紧凑高度。
3. Structure Map、Chapter Swimlane 与底部模块入口在首屏内形成完整纵向节奏。
4. 右侧 Agent 面板缩窄，提高单屏任务、记忆和审查信息密度。
5. 1180px 以下逐步简化装饰和密度；移动端继续使用现有单列折叠策略。

## 空间舞台

`CockpitVisualStage` 拆分为可独立调节的视觉层：

1. 基础纸白画布与微弱纹理。
2. 跨越左下至中央上方的绿色流体层。
3. 流体内部的高光、细线和粒子层。
4. 左下书本资产层。
5. Nova 吉祥物层。
6. 内容面板与交互控件层。

中央面板使用透明度、局部模糊和层级阴影维持可读性，同时允许流体在模块间隙和局部表面下方可见。书本和 Nova 共享光源、底部辉光与遮挡关系，形成一个场景组合。

## 核心组件

### AppShell

调整三栏尺寸、首屏高度和纵向节奏。组件职责与数据传递方式不变。

### StructureMap

保留 Act 选择逻辑，将展示改为紧凑节点卡与 SVG 贝塞尔曲线。叙事标记显示在关系线上方，当前 Act 使用描边、柔光和节点强调，不依赖大面积绿色填充。

### ChapterSwimlane

将章节卡压缩为连续节点链，显示章节编号、标题、字数和关键标签。章节间使用箭头或曲线表达推进关系，添加章节仍保留为末端节点。

### AgentPanel

压缩卡片间距、标题层级和任务行高度。状态颜色保持语义一致，减少无必要的外层卡片和重复描边。

### 底部模块

Inspiration、Character 与 Clue 模块在首屏内至少露出完整入口和主要内容概览，形成与参考图一致的创作闭环。
