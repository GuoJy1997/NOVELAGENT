# Novelora 沉浸式工作台视觉舞台设计

**日期：** 2026-07-14  
**状态：** 已确认，待实施  
**适用范围：** `apps/web` 的 Novelora Cockpit

## 1. 目标

在不重写现有三栏工作台和业务组件的前提下，将书本、薄荷绿色流体和 3D 吉祥物三张透明素材接入首屏，形成具有前景、中景、背景和遮挡关系的沉浸式视觉舞台。

本次设计采用用户确认的 **C 方案：沉浸海报式**。视觉资产贯穿工作台，但时间线、灵感库、人物关系图和 Agent 面板仍拥有清晰、稳定的阅读平面。

## 2. 设计语言契约

- **核心词：** 液态叙事工作台
- **用户情绪：** 灵感、陪伴、掌控感
- **母题：** 从打开的书中涌出故事能量，由 AI 写作伙伴协助编排
- **主材质：** 暖白陶瓷、半透明薄荷玻璃、柔和雾气、轻质纸张
- **空间结构：** 三栏工作台悬浮在一张完整视觉海报之上
- **字体性格：** 编辑感标题配合清晰、克制的无衬线正文
- **颜色骨架：** 暖白和浅灰绿为基底，薄荷绿为唯一主强调色；禁止紫蓝网格渐变和大面积高饱和色块
- **行为归档：** 小说结构、灵感、人物关系、线索和 Agent 状态继续由现有业务组件表达

## 3. 视觉层级

| 层级 | 内容 | 行为 |
| --- | --- | --- |
| L0 | 暖白背景、浅薄荷环境光 | 固定，不响应鼠标 |
| L1 | 绿色流体 | 从左下贯穿工作台并向右上延伸；低透明度 |
| L2 | 打开的书本 | 锚定左下，跨越侧栏与主工作区边界，允许裁切 |
| L3 | 三栏结构、内容阅读底膜 | 使用半透明暖白表面和有限模糊隔离背景 |
| L4 | 时间线、灵感库、人物图、线索图、控件和正文 | 最高阅读优先级，不被素材覆盖 |
| L5 | 3D 吉祥物 | 锚定右下并越界进入 Agent 区，形成前景遮挡 |
| L6 | 抽屉、对话框、焦点环等临时界面 | 始终高于吉祥物和装饰层 |

视觉资产均设置 `pointer-events: none`。书本和流体不得进入可访问性树；吉祥物本次仍作为装饰图，后续成为助手入口时再添加真实按钮语义。

## 4. 资产清单

| 资产 | 源文件 | 正式建议文件名 | 用法 |
| --- | --- | --- | --- |
| 书本 | `assets/generated/book-hero-alpha-v1.png` | `cockpit-book-hero.png` | `contain`，左下锚定 |

## 5. 组件边界

新增 `CockpitVisualStage`，只负责：

- 渲染背景环境光和三张视觉资产；
- 提供稳定的层级容器；
- 暴露可由 CSS 变量控制的缩放、偏移、透明度和模糊参数；
- 根据断点切换视觉密度；
- 遵循减少动态效果设置。

`AppShell` 继续负责侧栏、工作区和右侧 Agent 面板的结构。业务组件不直接引用三张大图，也不承担视觉舞台的定位逻辑。

## 6. 表面与可读性

- 工作台外壳使用低透明度暖白底膜，让流体仍然贯穿但不过度抢眼。
- 关键内容卡片使用更高不透明度的白色表面、轻边框和克制阴影。
- 不在所有组件上使用玻璃拟态；模糊只用于三栏底膜和必要的浮层。
- 正文、标签和按钮必须保持现有或更高的对比度。
- 书本不得覆盖侧栏导航文字，吉祥物不得覆盖 Agent 控件，流体不得降低图表连线辨识度。

## 7. 响应式规则

### 大于或等于 1180px

- 展示完整三栏和三张视觉资产。
- 书本跨越左侧栏与主工作区，吉祥物跨越右侧边界。
- 流体贯穿主工作区底部并向右上延伸。

### 900px 至 1179px

- 缩小书本与吉祥物，降低流体透明度。
- 保持现有横向工作台策略，不允许视觉资产制造额外横向滚动。

### 小于 900px

- 隐藏大书本。
- 流体仅保留低透明度局部背景。
- 吉祥物缩小为页面角落的视觉提示；本次不新增真实助手按钮行为。
- 所有业务内容保持单栏顺序和可操作性。

## 8. 动效故事板

### 页面进入

- **触发：** 工作台首次完成渲染
- **动作：** 流体淡入，书本上移少量距离，吉祥物轻微缩放进入
- **时长：** 450–700ms
- **实现：** CSS `transform` 与 `opacity`
- **降级：** 减少动态效果开启时直接显示最终状态

### 环境呼吸

- **触发：** 页面空闲
- **动作：** 流体以极小幅度改变透明度和位移
- **时长：** 8–12s
- **限制：** 不旋转、不闪烁、不影响阅读
- **降级：** 减少动态效果开启时停止

书本不做持续翻页，吉祥物不做无原因循环动作。后续只有 Agent 状态变化时，吉祥物才响应具体产品事件。

## 9. 性能策略

- 正式资产复制到 `apps/web/src/assets`，不从仓库根目录跨层引用。
- 保持原始透明 PNG 作为首版实现，实施后根据真实构建体积评估 WebP/AVIF。
- 动效仅改变 `transform` 和 `opacity`。
- 避免在大面积素材上持续运行高成本 CSS 滤镜。
- 装饰图片设置合理的尺寸约束，避免原始像素尺寸参与布局计算。

## 10. 验收标准

1. 首屏在移除文字后仍能看出“书本释放故事能量、AI 伙伴协助创作”的视觉世界。
2. 页面中不存在灰白棋盘格和洋红背景残留。
3. 三张素材具有明确的前后关系，而不是平铺在同一个背景层。
4. 时间线、正文、按钮和图表连线清晰可读。
5. 书本不遮挡导航，吉祥物不阻挡 Agent 面板控件。
6. 装饰层不拦截点击、滚动、键盘焦点或抽屉操作。
7. 现有交互测试继续通过，并补充视觉舞台结构测试。
8. Lint、单元测试和生产构建通过。
9. 桌面宽屏、窄屏和移动端截图均无溢出或意外裁切。
10. 减少动态效果开启时，布局和含义保持完整。

## 11. 非目标

- 本次不实现全局路由、真实后端数据或全局语言切换。
- 本次不重写现有信息架构和业务组件。
- 本次不把吉祥物改造成可点击 AI 助手入口。
- 本次不制作新的 3D 动画或视频素材。
- 本次不追求与参考图像素级复刻，而是恢复其空间分层和资产主导的设计方法。
