# Novelora 柔和空间化重构设计

日期：2026-07-23  
状态：用户已批准方案 2（空间层重构）

## 目标

以 `assets/参考图/image.png` 为视觉基准，纠正当前页面“层层描边的传统 Dashboard”倾向。在不改变信息架构、mock 数据和交互语义的前提下，让内容像参考图一样悬浮在连续的柔白薄荷背景中。

## 设计判断

- 顶部项目区不再作为带边框的独立容器，只通过留白和内容对齐建立层级。
- 左侧导航保留整体区域感，但不使用贯穿全高的硬直线；下半段边界被书本、流体和柔光自然消隐。
- 一级内容模块使用极弱边界、较大缓和圆角和低对比阴影；二级信息卡才保留清晰但轻薄的轮廓。
- 全局配色调整为约 90% 柔白、10% 薄荷绿。绿色主要用于交互状态、关系连线和局部环境光。
- 书本、Nova 与流体共同组成左下场景，不允许出现矩形裁切感或高饱和绿色色块。

设计参数：`DESIGN_VARIANCE 6`、`MOTION_INTENSITY 3`、`VISUAL_DENSITY 5`。

## 视觉层级

1. 柔白画布与极淡薄荷环境光。
2. 连续流体纹理和书本光晕。
3. 无框顶部内容、弱轮廓侧栏与右侧 Agent 区。
4. 半透明一级工作区模块。
5. 可交互二级卡片与状态强调。
6. Nova、书本局部前景和键盘焦点反馈。

## 验收标准

- 1440×900 下顶部没有完整边框或底部分隔线。
- 左侧栏没有从顶部贯穿到底部的直线边界。
- 书本区域能遮融侧栏下部轮廓，同时不遮挡导航与主工作区交互。
- Structure、Chapter 和底部三个模块的一级容器边界明显弱于内部卡片。
- 页面主体保持柔白，薄荷绿不形成大面积重色遮罩。
- 现有可访问性、响应式、reduced-motion、测试与构建均不回退。
