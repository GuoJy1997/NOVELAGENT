# Novelora 白绿液态工作台第一阶段设计

**日期：** 2026-07-17
**状态：** 已确认，待实施
**范围：** `apps/web` Novelora Cockpit 视觉重构，不改变现有业务行为

## 1. 纠偏目标

当前页面的问题不是素材缺失，而是视觉资产被旧后台设计语言压住：三栏拥有大面积不透明底膜，卡片继续使用珊瑚红、蓝色和琥珀色，书本与流体失去空间穿透，3D 吉祥物也没有承担品牌主视觉职责。

第一阶段要把页面从“带绿色装饰的普通后台”重构为“白绿液态叙事工作台”：即使暂时移除全部文字，首屏仍能通过书本、绿色流体和 3D 写作伙伴被识别。

## 2. 设计语言契约

- **核心词：** 白绿液态叙事工作台
- **风格家族：** Liquid Glass Cockpit + Tech Mascot Brand System
- **用户情绪：** 灵感、清洁、陪伴、掌控
- **母题：** 故事从打开的书中生长，流体将结构、人物、线索和 AI 串联
- **主材质：** 暖白陶瓷、薄荷液态玻璃、雾化树脂、柔和纸张
- **字体性格：** 现代、轻盈、清晰的无衬线编辑字体
- **禁止项：** 珊瑚红主选中态、蓝色主进度、琥珀色装饰、米黄色纸张后台、大面积纯白遮罩、右下角孤立小吉祥物

## 3. 色彩骨架

| Token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F7FBF9` | 页面暖白绿色基底 |
| `surface.glass` | `rgba(255,255,255,0.58)` | 一级面板 |
| `surface.card` | `rgba(255,255,255,0.82)` | 节点、章节卡片 |
| `mint.primary` | `#0AA85B` | 主按钮、选中态、关键连线 |
| `mint.support` | `#6FDDB1` | 流体高光、辅助进度 |
| `mint.soft` | `#DDF6EA` | 选中底色、Chip |
| `mint.line` | `#CFE8DD` | 边框和分割线 |
| `ink.primary` | `#14261F` | 主文字 |
| `ink.muted` | `#6C7D75` | 辅助文字 |

红、黄、蓝只用于错误、警告、运行状态等小面积语义反馈，不能继续作为页面装饰色或默认图表颜色。

## 4. 首屏空间结构

```text
L0  暖白基底与浅薄荷环境光
L1  从左下向右上贯穿的薄荷绿色流体
L2  左下打开的书本
L3  半透明侧栏、工作区与 Agent 信息表面
L4  结构节点、泳道、关系图、正文和控件
L5  左下书本前方的 3D 吉祥物
L10 抽屉、对话框和全局浮层
```

页面不得再有覆盖整个工作区的统一白色遮罩。流体必须能穿过主工作区的空白和一级面板，但不能降低文字与关系线可读性。

## 5. 左下品牌舞台

- 书本固定于左下，桌面宽屏宽度约 `340–430px`，允许从画布边缘裁切。
- 绿色流体从书脊位置出发，向结构图和右上区域扩散。
- 3D 吉祥物位于书本前方，桌面宽屏高度约 `180–220px`。
- 吉祥物与书本组成一个完整主视觉，不能拆散到无关联的两个角落。
- 左侧栏为品牌舞台预留底部空间，导航和项目卡片不能与吉祥物重叠。
- 右侧 Agent 卡片只显示由 3D 吉祥物裁切出的头部头像，不再使用旧 2D SVG 吉祥物。
- 吉祥物脚下的柔和接触投影和玻璃底座使用 CSS 制作，不新增位图。

## 6. 流体可见性

现有流体资产保留，但需要通过 CSS 提高薄荷绿色表现：

- 使用 `saturate`、`brightness` 和局部绿色环境光增强颜色；
- 桌面首屏可见度必须明显高于当前版本；
- 不使用整层低透明白膜覆盖流体；
- 流体边缘不能出现洋红、棋盘格或灰色脏边；
- 如果 CSS 调色后仍偏灰，才进入第二阶段重新生成原生透明流体。

## 7. 表面系统

### 页面结构表面

- 侧栏、工作区和右栏不再各自使用不透明白色矩形铺满视口。
- 一级面板使用 `rgba(255,255,255,0.52–0.66)`，配合 `backdrop-filter: blur(18–24px)`。
- 不支持模糊时使用约 `0.90` 的白色降级背景。

### 内容卡片

- 结构节点、章节卡片、任务卡片使用 `0.78–0.88` 的乳白表面。
- 边框统一为浅薄荷绿，不再混用米黄线框。
- 阴影使用低饱和绿色，不使用棕色纸张阴影。
- 选中态统一为祖母绿描边、浅薄荷底和绿色进度。

## 8. 字体与图标

- `--font-display` 与 `--font-ui` 统一进入现代无衬线体系。
- 页面标题允许使用较高字重，但不能继续使用厚重黑色 Georgia 风格。
- Logo、导航图标、模块图标统一改为绿色/深墨绿色。
- 优先修改现有 SVG 颜色或使用 `currentColor`，不重新生成位图图标。

## 9. 响应式

- `>=1440px`：展示完整左下书本、流体和 `180–220px` 吉祥物舞台。
- `1180–1439px`：缩小品牌舞台，保留书本和吉祥物，不遮导航或主内容。
- `901–1179px`：页面进入横向工作区时隐藏完整吉祥物，保留低干扰流体；避免与滚动内容脱锚。
- `<=900px`：隐藏大书本和完整吉祥物，保留轻量薄荷环境背景；Agent 卡片仍使用 3D 头像。

## 10. 动效

- 页面进入：书本和吉祥物以小幅位移、透明度进入，时长 `450–650ms`。
- 流体：只做极慢的呼吸和少量位移，时长 `10–14s`。
- 吉祥物：第一阶段不做无原因循环摆动。
- `prefers-reduced-motion: reduce` 下全部装饰动画停止。

## 11. 第一阶段非目标

- 不实现新路由、后端接口或真实 Agent 执行。
- 不重写时间线、人物关系图、灵感库的数据结构。
- 不新增吉祥物动作套图。
- 不重新生成流体，除非 CSS 调色经过截图验证仍不合格。
- 不追求参考图逐像素复刻，但必须恢复其白绿颜色骨架、素材主导、透明穿透和左下品牌舞台。

## 12. 验收标准

1. `1728×1117` 与 `1440×900` 首屏截图形成明确白绿视觉世界。
2. 左下书本和吉祥物组成一个完整品牌舞台，不再分散到右下角。
3. 流体贯穿主工作区且肉眼可见，不被统一白膜遮住。
4. 主选中态、按钮、进度和关系线以绿色为主；珊瑚红、蓝、琥珀色不再主导页面。
5. 一级面板具有背景穿透感，正文和连线仍清晰。
6. 右侧 Agent 卡片使用 3D 吉祥物头像，不出现旧 2D 吉祥物。
7. 书本和吉祥物不覆盖导航、项目卡片、主要按钮或正文。
8. `901–1179px` 与移动端不出现固定素材脱锚或根横向溢出。
9. 所有现有交互、焦点陷阱、Escape 关闭和焦点返回继续工作。
10. 单元测试、Lint、生产构建和真实浏览器截图验收通过。
