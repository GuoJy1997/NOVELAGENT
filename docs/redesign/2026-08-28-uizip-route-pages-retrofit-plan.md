# uizip 路由页面整改方案（ChatGPT 视觉稿 → 笔心实现）

> 依据：`d:\ui包\uizip` 下 7 张 ChatGPT 生成稿（首页 / 写作 / 人物 / 关系 / 大纲 / 世界观 / 工作流），
> 对照当前 `apps/web` 直播代码（`BixinHomePage` 壳 + `pages/`、`writing/` 各工作台页）。
>
> **风格定调**：7 张稿全部采用。首页用「妙笔」稿的活泼卡通风（高饱和、贴纸感、吉祥物），
> 6 张工作台页用白+绿清透风。两者共存不冲突：同一个壳（`BixinHomePage`）、同一套
> `--bixin-*` token 体系（首页新增一组高饱和强调色 token），**所有文案品牌名统一写「笔心」，
> 稿子里出现的「妙笔」字样一律替换**。
>
> 本文档分两部分：**第一部分是要让 ChatGPT 再生成的视觉资产**，**第二部分是代码改造**。

# 第一部分：ChatGPT 需要再生成的资产

统一生成要求（写进每条 prompt）：

- 与对应稿子同风格同色调；同一批角色/吉祥物资产在一次会话内生成，先出设定表再出图，保证同人同貌。

- 图内如出现文字，品牌名必须是「笔心」，不要出现「妙笔」。

# 第二部分：代码改造

通用前提（全部页面适用）：

- 一律画在 `BixinHomePage` 壳内，1416×786 设计画布 + `useFitScale` 等比缩放，不新开壳。
- `tokens.css` 新增一组首页强调色 token（紫 `--bixin-pop-purple`、粉、橙、黄等，取色自首页稿），首页专用；工作台页继续用现有白绿 token。改 token 前先过 `global.test.ts` 契约。
- 文案品牌名统一「笔心」；「妙笔小作家」类等级铭牌改为「笔心小作家」。

## 2.1 首页（P0，按 首页.png 重构）

现状：`HeroSection` + `HomeDashboard`（项目总览/进度/日历/人物网络卡）+ 场景/吉祥物/书本分层。

改造（首页从「场景+书」改为稿中的运营化仪表盘，原 scene/mascot/book 分层让位）：

1. Hero 区：背景层用资产 #2；左侧标题贴纸字（先用代码实现：超大黑体 + 绿色强调 + 白描边/投影，资产 #3 到位后可替换为图）+ 副标题胶囊 + 气泡贴纸；右侧主视觉机器人（资产 #1）。下方功能 chips 行（智能构思/角色鲜活/剧情联动/世界沉浸/一键成稿，lucide 图标）。
2. 三卡行：
   - 「今日创作挑战」紫渐变卡：主题/说明/奖励行 + 吉祥物（资产 #4）+「立即挑战」按钮 + 参与人数条。数据进 fixture，按钮接 toast。
   - 「AI 陪写」蓝紫卡：机器人头（资产 #5）+「需要我帮你」四个快捷按钮（续写下一章/优化剧情/描写场景/对话润色）+「开始陪写」→ 跳写作页并带上对应快捷能力。
   - 「快速生成」米色卡：吉祥物（资产 #6）+ 四项入口（小说大纲→大纲页、章节提纲→写作页、角色设定→人物页、世界设定→世界观页）。
3. 「最近项目」卡行：封面图（资产 #8）+ 类型徽章 + 书名 + 更新至章节 + 字数/进度条 +「新建作品」虚线卡。数据来自现有 project meta + fixture 补位。
4. 「AI 建议」卡：基于当前创作的推荐列表（fixture 文案）+「换一换」轮换。
5. 现有 `HomeDashboard` 四卡（项目总览/章节进度/日历/人物网络）：功能不删，内容合并进上述卡片体系或降级为第二屏；`BookForeground`/吉祥物分层在首页停用（组件保留，不删代码）。
6. 交互与 aria：卡片按钮全部可聚焦、`aria-label` 完整；跳转沿用 `onSelectNavigation`。

2. `ChapterList` → 章节树：按 卷/幕 分组折叠、行内字数、状态徽章（已完成✓/写作中/草稿/空）、搜索框、「新建章节」；底部「本章进度」卡（38/52 + 进度条 + 总字数）。缺的字段进 fixture。
3. `ChapterEditor` → 纸面编辑器：章节大标题 + 标签 chips、工具栏（最少实现 撤销/重做/B/I/U，其余展示态）、正文 textarea 套纸面样式；底部悬浮 AI 操作条（润色/扩写/改写/对话/Ask Hermes → 接现有 task/candidate 流程）；页脚统计条（本章字数/预计阅读/章节目标进度/自动保存时间）。

- `npm run test:web`、`lint:web`、`build:web` 全绿；保住现有 aria 契约（`aria-pressed`、`role="dialog"`、焦点恢复）。

- 颜色/阴影/圆角只用 `tokens.css` 变量；首页新强调色以新增 `--bixin-pop-*` token 落地，不散写色值；改 token 先过 `global.test.ts`。
