# Novelora UI Asset Pack

这是为了还原“明亮潮玩风格 AI 小说写作工作台”准备的视觉资产包。

使用建议：

1. 先导入 `00_design_system/css_variables.css`。
2. Logo、icons、badges 直接作为 SVG component 使用。
3. Project covers、inspiration thumbnails、character portraits 可先作为占位资产。
4. Mascot SVG 可用于左侧大展示、右侧 agent 头像和空状态。
5. 纸纹 PNG 以 `mix-blend-mode: multiply; opacity: .18` 覆盖在 app 背景上。
6. UI 卡片、连接线、进度条、图谱节点尽量用代码实现，保证清晰度和交互性。

注意：本包是前端还原用的“可落地资产”，不是最终商业插画精修版。正式上线前建议把 mascot 和项目封面替换成专业 3D 渲染或统一插画系统。
